# FocusSync UI System

==================================================
FRAMEWORK
==================================================

- TailwindCSS
- DaisyUI

==================================================
THEME
==================================================

Mode:
- Dark Mode ONLY

Primary Colors:
- Purple
- Blue

Accent Style:
- Gradient (purple → blue)
- Glow effects (minimal)

==================================================
UI STYLE RULES
==================================================

- Minimal UI (no clutter)
- Glassmorphism cards
- Rounded corners (xl / 2xl)
- Soft shadows only
- Smooth animations (200–300ms)

==================================================
LAYOUT RULES
==================================================

- Responsive design mandatory
- Mobile-first approach
- Grid-based layout
- Sidebar for desktop
- Bottom navigation for mobile

==================================================
COMPONENT RULES
==================================================

Buttons:
- rounded-xl
- gradient background
- hover scale (1.02)

Cards:
- glass effect
- padding consistent

Inputs:
- clean border
- focus glow effect

==================================================
DASHBOARD STYLE
==================================================

- Focus timer at center
- Task list on side
- Activity stats cards
- Minimal distractions

==================================================
FOCUS MODE UI
==================================================

- Full screen dark mode
- Only timer visible
- Blocked state animation
- Warning minimal popup

==================================================
ANIMATION RULES
==================================================

- No heavy animations
- Only smooth fade/scale
- Avoid laggy effects

==================================================
IMPORTANT
==================================================

UI must always be:
- Clean
- Fast
- Minimal
- Focus oriented
